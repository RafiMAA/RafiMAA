## 🩺 Dual-Signal OOD Gating for Skin Cancer Detection

**Computer Vision · Deep Learning · Reliable AI · OOD Detection**

A research prototype investigating **open-set skin cancer classification**
using a ResNet50 classifier together with complementary
out-of-distribution detection signals.

The system combines:

- Vision Transformer embedding distance
- Energy-based scoring
- ReAct-based feature processing
- Dual-signal OOD gating
- Confidence-based acceptance/rejection

The project focuses on reducing the risk of blindly classifying
inputs that may fall outside the model's known distribution.
