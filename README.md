# 👨‍💻 About Me

I am a **Computer Engineering undergraduate at the University of
Moratuwa, Sri Lanka**, with strong interests across **robotics,
artificial intelligence, computer vision, embedded systems, and
autonomous systems**.

My work combines **robotics, control, sensing, embedded computing and
software engineering** with **machine learning, computer vision and
reliable AI**, allowing me to explore intelligent systems from both
their **physical engineering** and **computational** sides.

I am especially interested in systems where **robots, sensors, embedded
controllers, machine learning models and autonomous perception work
together reliably in real-world environments**.

# 🧪 Engineering & Research Workflow

::: {align="center"}
``` text
Problem
  ↓
System / Domain Understanding
  ↓
Engineering Model
  ↓
Hypothesis / Design Goal
  ↓
Implementation
  ↓
Experimentation
  ↓
Measurement & Quantitative Evaluation
  ↓
Failure Analysis
  ↓
Validation
  ↓
Reproducibility
```

### My Approach

**Understand the system → model it → build it → measure it → test its
